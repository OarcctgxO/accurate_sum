Эта функция - главный элемент моей программы по нахождению оптимальной комбинации упаковок для получения запрашиваемой суммы.

Принимает:
needed (положительное целое число) - запрашиваемое число, сумму которого нужно найти;
nums (список положительных целых чисел) - доступные элементы, из которых собирается сумма needed;
mode - указание метода подбора (по умолчанию 'exact'), или, упрощая, что делать, если сумма не найдена:
    exact - поднятие ошибки ValueError;
    top - найти ближайшую достижимую сумму сверху;
    bot - найти ближайшую достижимую сумму снизу.
Выводит:
final_list (список положительных целых чисел) - использованные для суммы элементы из nums.

Если m = len(nums), n = needed, то:
    Временная сложность:
        O(m * log(m) + m * n) или O(m * (n + log(m)))
    Сложность по памяти:
        O(n)

Если вариантов составления суммы несколько, выбирается тот, в котором наименьшее число больше (см. пример 2).
Если вариантов с одним и тем же наименьшим числом несколько, выбирается тот, в котором предыдущее наименьшее число больше (см. пример 3).

Пример 1:
ввод: (18, [5, 5, 6, 2, 3]);
вывод: [6, 5, 5, 2].

Пример 2:
ввод: (1002, [1000, 334, 334, 334, 2]); # 334 + 334 + 334 = 1000 + 2
вывод: [334, 334, 334].

Пример 3:
ввод: (12, [5, 5, 6, 4, 2]); # 5 + 5 + 2 = 6 + 4 + 2
вывод: [5, 5, 2]

Пример 4:
ввод: (20, [5, 4, 3, 2, 1]); # 5 + 4 + 3 + 2 + 1 = 15 < 20
вывод: ValueError: Запрашиваемая сумма несоставима этими элементами.

Пример 5:
ввод: (19, [5, 5, 6, 4, 2], mode='top'); # 5 + 5 + 6 + 4 = 20 > 19
вывод: [6, 5, 5, 4].

Пример 6:
ввод: (19, [5, 5, 6, 4, 2], mode='bot'); # 5 + 5 + 6 + 2 = 18 < 19
вывод: [6, 5, 5, 2].

Пример 7:
ввод: (20, [5, 4, 3, 2, 1], mode='top'); # 5 + 4 + 3 + 2 + 1 = 15 < 20
вывод: [5, 4, 3, 2, 1].

Пример 8:
ввод: (20, [5, 4, 3, 2, 1], mode='bot'); # 5 + 4 + 3 + 2 + 1 = 15 < 20
вывод: [5, 4, 3, 2, 1].
